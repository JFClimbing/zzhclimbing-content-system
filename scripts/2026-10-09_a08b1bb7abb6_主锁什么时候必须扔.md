**（独立钩子）**

**你包里那把主锁，用了几年了？** 大部分人答不上来。

更麻烦的是，很多人判断一把锁该不该扔，靠的是「感觉它还结实」。这条给你三个硬标准，都不用感觉。最后有张检查表，先别看走。

【画面 2｜20-40s】特写锁门开合，慢放回弹。字幕：「✅ 弹到位 / ❌ 留缝」

**第一个，门。** 主锁的门是有回弹的——松手它会自己弹回去、弹到位。如果它开始发涩、弹不回去、或者弹回去了但留着一丝缝，这锁就该退了。锁门是主锁最关键的承力部分之一，门的开合不正常，说明锁门机构已经出问题了。

【画面 2｜20-40s】特写锁门开合，慢放回弹动作。字幕打「✅弹到位 / ❌留缝」

**第二个，磨损。** 看锁身跟绳子长期摩擦的那一面。如果磨出了明显的平坑、或者你能摸到一个平台——那不是"用出感情了"，那是截面在变细。

【画面 3｜40-70s】手指划过磨损面，特写那个平面。字幕：「摸得出台阶 = 退」很多厂家给的判据是磨损到一定程度就不能再用，具体数值看你这把锁的说明书。但我自己的标准是：凡能明显摸出平面，就退。这里我不跟你讨论"还能用多久"，因为没有意义。

**第三个，受力历史。** 这把锁如果承受过冲坠、被重物砸过、从高处掉在硬地上、或者接触过强酸碱，直接退，不讨论。金属内部的变化是看不出来的，外观完好不代表结构完好。

【画面 4｜70-95s】快剪：被砸过的锁、变形边缘、铆钉松动特写

**【这一段上屏幕上表 —— 出门前照着过一遍】**

| 检查项 | ✅ 还能用 | ❌ 当场退 |
|---|---|---|
| **锁门回弹** | 松手自动弹到位、贴合无缝隙 | 发涩 / 弹不回 / 弹回后留一丝缝 |
| **锁门铆钉** | 紧固、不晃 | 有松动 |
| **锁身磨损** | 表面均匀，摸不出台阶 | 摸得出平面 / 平坑 |
| **边缘** | 圆润 | 出现锋利毛刺 |
| **受力历史** | 正常攀爬使用 | 冲坠过 / 被重物砸过 / 从高处摔在硬地 / 接触强酸碱 |
| **外形** | 原状 | 任何可见变形 |

**判定原则**

【画面 5｜表格全屏静止 3 秒】口播：出门前照着过一遍，这张截一下：六项里任意一项落进右列 → 退。**不确定 → 退。** 没有"再观察一下"这个选项。这一点上"看起来没事"完全不能作为依据。

我知道有人会说"我这锁好几百块呢"。对，好几百。你的踝关节多少钱？不确定就扔，这是这个领域里唯一不会后悔的决定。另外补一句：退下来的锁别转手卖，尤其别卖给不知道它历史的人——你不知道的事，别人也不该替你承担。
